# CUSTOM.LAB — демо-лендинг

Готовый статический сайт без сборщиков: HTML + CSS + JS.

## Как запустить

1. Распакуй архив.
2. Открой `index.html` двойным кликом.
3. Лучше запускать через VS Code + Live Server, если собираешься редактировать.

## Что уже работает

- адаптив под телефон;
- липкое меню;
- интерактивное поле для рисования мышкой;
- бегущая строка;
- фильтры каталога;
- многошаговая форма заказа;
- выбор вариантов кнопками;
- загрузка и локальный предпросмотр референсов;
- генерация текста заявки;
- копирование заявки;
- переход в Telegram;
- FAQ.

## Telegram

Открой `script.js` и замени:

```js
telegramUsername: 'your_username'
```

на свой ник без `@`, например:

```js
telegramUsername: 'ketov_custom'
```

Сейчас сайт статический, поэтому он не может сам отправить файлы и заявку напрямую боту без серверной части. Он собирает текст заявки, позволяет его скопировать и открывает Telegram.

Если нужна настоящая автоматическая отправка заявки мастеру вместе с фотографиями — можно добавить небольшой backend на Flask/FastAPI или Cloudflare Worker + Telegram Bot API.

## Что менять под себя

- Название `CUSTOM.LAB` — в `index.html`.
- Цвета — переменные в самом начале `styles.css`.
- Цены и тексты — `index.html`.
- Работы — блок `.work-grid`. Сейчас вместо фото стоят дизайнерские заглушки.
- Telegram — `script.js`.
